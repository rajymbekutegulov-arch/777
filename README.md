# ЕНТ · Школа №8

Платформа подготовки к ЕНТ для учеников школы №8: **география**, **математическая грамотность и математика**, **история Казахстана**. Объяснения, тренировочные задания, тематические тесты, пробные варианты ЕНТ, личный прогресс и учительская панель — на русском и казахском языках.

Проект готов к запуску: **без npm-зависимостей и сборки**, нужен только Node.js 20+.

---

## Быстрый старт

```bash
npm start
```

Откройте **http://127.0.0.1:4173**.

При первом запуске автоматически создаётся `data/db.json` с демонстрационными аккаунтами и стартовым учебным курсом.

| Роль | Почта | Пароль |
| --- | --- | --- |
| Ученик | `student@school8.kz` | `student123` |
| Учитель | `teacher@school8.kz` | `teacher123` |

На странице входа есть кнопки «Войти как ученик» и «Войти как учитель» — они подставляют демо-данные.

Другой порт (PowerShell):

```powershell
$env:PORT=4174; npm start
```

Остановка — `Ctrl+C`.

## Что реализовано

### Для ученика
- Регистрация и вход, безопасное хранение пароля (scrypt) и HttpOnly-сессия.
- Личный кабинет: имя, язык, общий прогресс, статистика по предметам, последние результаты.
- Продолжение обучения с последней открытой темы.
- Сохранение завершённых тем, баллов и результатов тестов на сервере.
- Темы для повторения — тесты ниже проходного балла.
- Последовательный путь: урок → практика → тематический тест → пробный вариант ЕНТ.
- Практика с мгновенной проверкой и объяснением каждого ответа.
- Тесты с таймером (для пробного варианта), навигацией по вопросам и подтверждением завершения.
- Результаты с процентом, проходным баллом, разбором всех ответов и возможностью пересдачи.
- Работа на телефоне, планшете и компьютере.

### Для учителя
- Отдельная панель `/teacher`, доступная только аккаунтам с ролью `teacher` (проверка на сервере).
- Редактирование предметов: название, подзаголовок, описание.
- Создание предметов, тем, пробных вариантов.
- Редактор темы: объяснение в Markdown, длительность, практика, тематический тест, проходной балл.
- Редактор вопросов: 2–6 вариантов, правильный ответ, пояснение; добавление и удаление вопросов/вариантов.
- Переключение языка редактирования RU/KZ внутри формы.
- Экспорт и импорт всего курса в JSON (резервная копия / перенос материалов).
- Изменения сохраняются на сервере в `data/db.json` и сразу видны ученикам.
- Удаление предметов и тем с подтверждением (связанные результаты тоже удаляются).

### Языки
- Полностью переведённый интерфейс: RU / KZ.
- Все учебные материалы и вопросы хранятся в двух языках.
- Переключатель языка есть в шапке на всех страницах, включая мобильные.
- Выбор сохраняется в `localStorage` и в профиле ученика.

### Дизайн и доступность
- Адаптивная вёрстка от 360 px до широких экранов, отдельные макеты для телефона.
- Единая дизайн-система, цветовые темы предметов, мягкие градиенты, аккуратная типографика.
- Видимый фокус, клавиатурная навигация, `aria`-атрибуты, live-region для уведомлений, `prefers-reduced-motion`.
- Состояния загрузки, ошибок, пустых списков и успешных действий.
- Контрастный текст и крупные области нажатия.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm start` | запуск сервера на `127.0.0.1:4173` |
| `npm run dev` | запуск с авто-перезапуском при изменении серверных файлов |
| `npm run check` | проверка стартового курса: структура, RU/KZ, ответы, повторы id |
| `npm run smoke` | 27 end-to-end проверок API (сервер должен быть запущен) |
| `npm run reset-db` | сброс базы к демо-данным (старая база сохраняется в `data/db.json.backup-*`) |

Перед `npm run smoke` запустите сервер в другом терминале.

## Как устроен учебный контент

Стартовый курс лежит в `server/seed/*.js` и содержит:

- 3 предмета;
- 13 тем с объяснениями (Markdown) на двух языках;
- 134 вопроса: практика, тематические тесты и пробные варианты;
- у каждого вопроса — 4 варианта, правильный ответ и объяснение.

Формат темы:

```js
{
  id: 'geo-1',
  order: 1,
  title: { ru: '…', kz: '…' },
  summary: { ru: '…', kz: '…' },
  duration: 12,
  lesson: { ru: '## Заголовок\n\nТекст…', kz: '…' },
  practice: [question, question, question],
  quiz: {
    title: { ru: 'Тематический тест', kz: 'Тақырыптық тест' },
    passScore: 70,
    questions: [question, question, question, question, question]
  }
}
```

Вопрос:

```js
{
  id: 'geo-1-p1',
  text: { ru: '…', kz: '…' },
  options: [{ ru: '…', kz: '…' }, …],
  correct: 0,
  explanation: { ru: '…', kz: '…' }
}
```

Учитель может менять материалы через панель — перезапуск сервера не требуется. Для массового редактирования используйте экспорт/импорт JSON. После изменения `server/seed/*.js` выполните `npm run reset-db` или удалите `data/db.json`, чтобы новые материалы попали в базу (сид применяется только при создании базы).

Поддерживаемый Markdown в объяснениях: `##`/`###` заголовки, абзацы, списки `-` и `1.`, `**жирный**`, `*курсив*`, цитаты `>` (оформляются как подсказка). HTML и изображения не поддерживаются.

## API (кратко)

| Метод | Путь | Доступ |
| --- | --- | --- |
| `POST` | `/api/auth/register`, `/api/auth/login`, `/api/auth/logout` | все |
| `GET` | `/api/auth/me` | все |
| `PATCH` | `/api/me` | ученик/учитель |
| `GET` | `/api/content`, `/api/topics/:id`, `/api/practice/:id`, `/api/quiz/:id`, `/api/exam/:id` | все |
| `POST` | `/api/attempts` | ученик/учитель |
| `GET` | `/api/attempts/:id`, `/api/me/progress`, `/api/me/attempts` | владелец / учитель |
| `GET` | `/api/teacher/content`, `/api/teacher/export` | только учитель |
| `PATCH`/`POST`/`DELETE` | `/api/teacher/subjects…`, `/api/teacher/topics…` | только учитель |
| `POST` | `/api/teacher/import` | только учитель |

Правильные ответы и пояснения тестов не отдаются ученику до завершения попытки: проверка выполняется на сервере.

## Безопасность и ограничения

Уже сделано:

- пароли хранятся как scrypt-хэш с солью;
- сессия — случайный токен в HttpOnly/SameSite=Lax cookie, срок 30 дней;
- серверная проверка роли для всех учительских операций;
- валидация всех материалов и ответов на сервере;
- CSP, `X-Content-Type-Options`, `X-Frame-Options`, защита от path traversal;
- ограничение размера запроса и попыток входа.

Для публичного размещения в интернете дополнительно нужно:

- HTTPS и флаг `Secure` у cookie;
- реальная СУБД (PostgreSQL/SQLite) вместо одного JSON-файла;
- резервное копирование и несколько инстансов приложения (файловая база рассчитана на один процесс);
- восстановление пароля и подтверждение почты — сейчас этих функций нет;
- журналирование действий учителя и модерация контента.

`data/db.json` не следует коммитить: он содержит аккаунты учеников и их результаты.

## Демо-режим и честность данных

- Регистрация, вход, прогресс и учительские изменения **реально сохраняются на сервере** в `data/db.json`.
- Если сервер остановлен, сайт показывает баннер «Сервер недоступен» и не выдаёт ложных сообщений об успешном сохранении.
- Встроенные демо-аккаунты предназначены для проверки сайта. Пароли от них указаны в README и на странице входа.
- Учебные материалы — демонстрационные, составлены по школьной программе. Перед использованием в реальной подготовке учителю стоит проверить факты и дополнить курс своими темами.
